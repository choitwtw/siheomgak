# CSV 템플릿 설명

이 폴더의 CSV 파일은 **헤더(컬럼명)만 있는 빈 템플릿**입니다. 행을 채워서 앱의 관리자 대시보드 → 「데이터」 탭에서 업로드하면 됩니다.
채워진 예시가 필요하면 `data/sample/` 폴더(기본 가상 데이터)를 참고하세요.

## 공통 규칙

- 인코딩: UTF-8 (엑셀에서 저장할 때는 「CSV UTF-8」 권장). CP949도 읽을 수 있습니다.
- 컬럼명은 영문(예: `student_id`)과 한국어(예: `학번`) 둘 다 받습니다. 컬럼 순서는 상관없습니다.
- 학과명은 이과대학 6개 학과 중 하나: 물리학과, 수학과, 생물학과, 지리학과, 정보디스플레이학과, 화학과
- 요일은 `월 화 수 목 금`, 시각은 `HH:MM`(24시간, 예: `13:30`).
- 시간대는 `요일 HH:MM-HH:MM` 형식이고 여러 개는 세미콜론(`;`)으로 구분합니다. 예: `수 13:00-18:00; 금 09:00-12:00`. 요일 대신 `매일`도 됩니다.
- 5개 파일을 한 번에 올리려면 ZIP으로 묶어 업로드하세요 (파일명은 아래 이름 그대로).
- 업로드 시 컬럼·값을 검사하고, 틀린 부분은 「몇 행, 어떤 컬럼, 무엇이 문제인지」 한국어로 알려 줍니다.

## students.csv — 학생

| 컬럼 | 한국어 이름 | 필수 | 설명 | 예시 |
|---|---|---|---|---|
| `student_id` | 학번 | 필수 | 학생 고유 번호 | `2026010001` |
| `name` | 이름 | 필수 | 학생 이름 | `김민준` |
| `major` | 주전공 | 필수 | 주전공 학과명 (이과대학 6개 학과 중 하나) | `물리학과` |
| `grade` | 학년 | 필수 | 1~4 | `2` |
| `double_major` | 복수전공 | 선택 | 복수전공 학과명, 없으면 빈칸 | `수학과` |
| `minor` | 부전공 | 선택 | 부전공 학과명, 없으면 빈칸 | (빈칸) |

## courses.csv — 과목

| 컬럼 | 한국어 이름 | 필수 | 설명 | 예시 |
|---|---|---|---|---|
| `course_code` | 과목코드 | 필수 | 과목 고유 코드 | `PHY201` |
| `course_name` | 과목명 | 필수 | 과목 이름 | `역학1` |
| `department` | 개설학과 | 필수 | 개설 학과명 | `물리학과` |
| `target_grades` | 대상학년 | 필수 | 쉼표로 구분한 대상 학년 | `2,3` |
| `professor_id` | 담당교수 | 필수 | 교수ID (professors.csv의 professor_id) | `P01` |
| `class_days` | 수업요일 | 필수 | 정규 수업 요일, 쉼표 구분 (월~금) | `월,수` |
| `class_start` | 수업시작 | 필수 | 정규 수업 시작 시각 HH:MM | `10:30` |
| `class_end` | 수업종료 | 필수 | 정규 수업 종료 시각 HH:MM | `11:45` |
| `class_room` | 정규강의실 | 필수 | 정규 강의실 ID (rooms.csv의 room_id) | `이과대학-101` |
| `enrollment` | 수강인원 | 선택 | 수강 인원 (비우면 수강내역에서 자동 계산) | `48` |
| `exam_type` | 시험방식 | 필수 | 수업시간 / 별도 / 없음 (a/b/c 도 가능) | `별도` |
| `exam_minutes` | 시험시간 | 필수 | 시험 시간(분): 60, 75, 90, 120 | `90` |

## professors.csv — 교수

| 컬럼 | 한국어 이름 | 필수 | 설명 | 예시 |
|---|---|---|---|---|
| `professor_id` | 교수ID | 필수 | 교수 고유 ID | `P01` |
| `name` | 이름 | 필수 | 교수 이름 | `이서연` |
| `department` | 소속학과 | 필수 | 소속 학과명 | `물리학과` |
| `courses` | 담당과목 | 선택 | 담당 과목코드, 쉼표 구분 (비우면 과목표에서 자동 계산) | `PHY201,PHY301` |
| `unavailable` | 불가시간 | 선택 | 시험 불가 시간대, 세미콜론 구분 (요일 HH:MM-HH:MM) | `수 13:00-18:00; 금 09:00-12:00` |
| `preferred` | 선호시간 | 선택 | 선호 시간대, 형식 동일. '매일 09:00-12:00' 처럼 매일도 가능 | `매일 09:00-12:00` |

## rooms.csv — 강의실

| 컬럼 | 한국어 이름 | 필수 | 설명 | 예시 |
|---|---|---|---|---|
| `room_id` | 강의실ID | 필수 | 강의실 고유 ID | `이과대학-101` |

| `departments` | 사용학과 | 필수 | 사용 가능 학과, 쉼표 구분. 모든 학과 공용이면 '전체' | `물리학과,수학과` |

## enrollments.csv — 수강 내역

| 컬럼 | 한국어 이름 | 필수 | 설명 | 예시 |
|---|---|---|---|---|
| `student_id` | 학번 | 필수 | 학번 (students.csv) | `2026010001` |
| `course_code` | 과목코드 | 필수 | 과목코드 (courses.csv) | `PHY201` |

## 시험 방식 (courses.csv의 `exam_type`)

| 값 | 의미 |
|---|---|
| `수업시간` (또는 `a`) | 시험 주간의 정규 수업 요일·시간·강의실에서 시험. 수업 요일이 여러 개면 **첫 번째 요일**에 시험. 그 시간에는 수강생의 다른 시험을 잡을 수 없음 |
| `별도` (또는 `b`) | 알고리즘이 시간과 강의실을 배정 |
| `없음` (또는 `c`) | 시험 없음(과제 대체). 시험 주간에도 정규 수업이 진행되므로 수강생은 그 시간에 다른 시험 불가 |

## 다른 AI 도구로 데이터를 만들 때 요청 예시

> 위 컬럼 설명을 그대로 붙여 넣고 "이 형식에 맞는 courses.csv를 30행 만들어 줘. professor_id는 P01~P20, class_room은 rooms.csv의 room_id 중에서 골라 줘" 처럼 요청하면 됩니다.
> 테이블 사이의 ID(교수ID, 강의실ID, 학번, 과목코드)가 서로 맞아야 합니다. 맞지 않으면 업로드 시 어떤 값이 없는지 알려 줍니다.
