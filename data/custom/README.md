# 사용자 데이터 (기본 데이터로 쓰기)

이 폴더에 아래 이름의 CSV를 넣으면, 앱을 열 때 가상 데이터 대신 이 데이터를 **기본 데이터**로 씁니다.

- `students.csv`, `enrollments.csv`, `courses.csv`, `professors.csv`, `rooms.csv` 중 **있는 것만** 바꿉니다.
  없는 표는 가상 데이터(시드 42)를 그대로 씁니다.
  - 예: KHU CHAT으로 학생 데이터만 만들었다면 `students.csv` + `enrollments.csv` 두 개만 넣으면 됩니다.
    이때 `enrollments.csv`의 과목코드는 가상 데이터 과목코드(`data/sample/courses.csv`)를 써야 합니다.
- 컬럼 형식은 `data/templates/README.md` 참고. 업로드 화면과 같은 검사를 거칩니다.
- 오류가 있으면 앱은 멈추지 않고 가상 데이터로 시작하며, 관리자 대시보드 → 데이터 준비 탭에 무엇이 틀렸는지 한국어로 보여 줍니다.

## 지금 들어 있는 데이터

- 원본: `source/dataset_2026-2.xlsx` (시트: 강의실·교수·과목·학생·수강내역)
- 변환: `python scripts/import_xlsx.py data/custom/source/dataset_2026-2.xlsx` (openpyxl 필요) → 이 폴더의 CSV 5종
- 규모: 학생 500명, 과목 48개(시험 42개: 별도 26·수업시간 16, 시험 없음 6), 교수 30명, 강의실 40개, 수강 내역 2,632건
- 변환 규칙과 판단
  - 강의실ID는 엑셀의 `R001` 대신 강의실명(`공용강의실-A01`)을 써서 화면에서 바로 알아보게 했습니다.
  - 시험좌석은 좌석의 2/3(띄어 앉기)가 기본이지만, **공용대형강의실 3곳은 좌석 전체(200석)**로 두었습니다.

    바꾸려면 `rooms.csv`의 `exam_capacity`를 고치면 됩니다.
  - 교양 과목은 원본에 없어 넣지 않았습니다.
